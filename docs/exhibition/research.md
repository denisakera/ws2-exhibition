# Research behind the provocations ("Čím se může stát?")

Every provocation on screen has two voices: **VÍME** (a checked statement) and **DOMNĚNKA** (a guess
that goes beyond it). This file lists what each "VÍME" rests on, so the collective can check or replace
it. Checked on 2026-10-19 (radiation, waste and applications rows added the same day) from the sources' own abstracts and pages; the texts were not read in full,
so please verify before printing.

# Může hmota počítat? / Can matter compute?

Touchscreen artwork of the Paleofuture Lab (*Lady Lovelace's Objection*, 2026): a **simulation** of reservoir computing (rezervoárové počítání) with WS₂ nanotubes, shown beside real, unconnected samples and an oscilloscope. Czech first, English switch. Nothing on the screen is live or measured on the sample beside it; recorded data come from the lab repository https://git.tami.sh/yair/ws2.

- Live: https://ws2.anonette.net (phones get `mobile.html`)
- Installation: `expo.html` (1920×1080 stage, kiosk with `?kiosk=1`), `start-exhibition.bat`
- Offline venue build: `bash tools/make_offline.sh` → `dist/ws2-offline/` (needs only Chrome or Edge)
- Tests: `node test/test_expo_copy.mjs`, `node test/test_expo_preprocess.mjs`
- Documentation: `docs/exhibition/`

SEM image of the nanotubes: Vojtěch Jeremiáš Kundrát. Credits are shown on the page.
